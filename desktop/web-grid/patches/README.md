# Tabulator 兼容性补丁

`tabulator-tables+6.5.2.patch` 修复锁定版本的 `SelectRange` 横向可见区：原实现只扣除行号宽度，导致键盘选中的非冻结单元格仍藏在左侧或右侧冻结列后。现在使用全部可见冻结列的左右宽度，并让冻结目标保持水平位置；纵向滚动和选区数据规则继续使用上游实现。

补丁同时包含 npm 包实际导出的 ESM、CJS 和对应源文件；只改源文件不会影响本项目。`npm ci` 的 `postinstall` 使用 `patch-package --error-on-fail`，补丁不匹配时安装失败。升级 Tabulator 时应检查上游修复，运行行为契约后更新或移除此补丁，不沿用旧版本补丁。

当前支持范围是产品使用的 LTR、非分组冻结列、普通水平渲染。RTL、水平虚拟渲染及冻结分组仍保留上游兼容性诊断。没有关闭范围选择、冻结能力或 renderer 诊断。

`src/grid/frozenRangeCompatibility.test.ts` 调用真实锁定库的键盘和鼠标处理器，仅补足 jsdom 不提供的几何：覆盖左右冻结、双向导航、冻结目标纵滚不横滚、跨区拖选数据和横滚后的选区几何。浏览器中的遮挡和布局仍由真实产品 E2E 验证。

`Filter` 补丁让已替换列或表头编辑器保留的回调失效。上游 `setColumns` 不触发单列删除事件，旧输入的默认 300ms 回调仍可提交筛选并触发 remote reload，清空较晚到达的宿主权威记录。回调入口核对当前列和当前编辑器；程序化设置筛选、当前输入及默认延迟保持原有行为。

`src/grid/dataSourceViewState.test.ts` 使用真实 Tabulator 输入事件和可控时钟，覆盖恢复空/非空筛选后新记录到达、同列重建表头、旧输入延迟/失焦回调，并验证替换后的输入仍在默认延迟后提交。
