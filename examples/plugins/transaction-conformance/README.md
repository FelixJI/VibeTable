# 合成事务示例

用当前仓库的 SDK/CLI 构建并在兼容 Host 中安装。全部编号及金额均为从空白构造的合成数据。

先创建模型，再经原生确认登记保护规则。预览三表计划不会创建业务行；确认后一次创建限额为 `10.00` 的头、数量 `8.00` 的行和同额分配。再次占用 `8.00` 必须被权威余额规则拒绝，不能留下第二条行或分配。

保存原请求 ID，关闭页面后输入它查询原结果。相同 ID 的再次提交返回原结果；未知 ID 不会创建新计划。示例不自动重试，不把查询失败或未知结果解释为零写入。

数据集按钮继续消费这个模型的 canonical 绑定。先用公开受保护事务预览并确认 200 对 `0.01` 行与分配，随后在一个三表数据集中读取两表各 201 行；两边汇总均为 `10.00`。总览、分页明细和原生 CSV 保存使用同一 datasetId/来源版本，后续改动明确失效，需要显式重开。页面重挂载释放数据集和有界订阅。

需要增量契约 `compatibility.dataset: vibetable.plugin-dataset.v1`；CSV 仍要求 `files:["pickWrite"]` 原生授权，不给插件文件路径。S56 保持原事务回归；S57 验证公开建模→原子事务→数据集→原生保存组合，并用独立 CSV/Decimal 读取器核对明细和逐分总额。
