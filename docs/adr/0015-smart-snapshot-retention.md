# ADR 0015：默认智能快照保留

- 状态：已接受
- 日期：2026-10-26
- 替代 ADR 0007 中新工作区的快照默认规则；旧工作区策略不自动覆盖。

新工作区使用 `snapshotBuckets: ["smart"]`、`snapshotDays: 730`、
`snapshotCount: 50`。智能模式不能与自定义桶混用：最近 24 小时按小时、
30 天按天、180 天按周、更早按月选择最新快照，各窗口都不超过用户指定的最长天数。
分桶使用 UTC，界面时间使用操作系统本地时区。最近 50 个及固定快照额外保留，
因此最长天数不是强制删除期限。

现有工作区的自定义桶继续按原有窗口计算。用户点击“恢复默认”只修改草稿，
保存时仍检查策略修订号。旧的 `retention-policy.json` 属于冻结的历史兼容包样本，
保留原内容；当前智能策略样本为 `retention-policy-smart.json`。

自动快照在有改动后空闲 5 分钟触发，持续编辑最长间隔 30 分钟。
手动快照默认固定，恢复前保护快照、活动根、持久 pin 和未完成发布仍优先保护。
文件历史的当前已发布根仍引用全部修订；在可事务发布裁剪根之前，
文件修订天数与数量不代表会物理清理这些修订。回收站宽限期保持 90 天。

清理仍使用既有预览、权威 inventory 校验和失败关闭机制，不改变空间限额行为。
旧 reader 不能理解智能桶时应拒绝读取，不应把它解释为空策略后清理数据。
