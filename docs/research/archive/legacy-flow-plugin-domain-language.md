# VibeTable 插件与自动化上下文

本文件定义插件与 Directus Flow 集成时使用的领域语言。实现和界面文案应优先采用这些术语，避免把不同所有权或不同运行位置的概念混为一谈。

## 术语

### 项目

当前连接的一个 Directus 数据源，也是插件安装、配置、Flow 绑定和审计记录的归属范围。同一插件可以分别安装到不同项目，但每个项目只有一个当前实例。

_避免：_ 工作区、数据库、站点（这些词在其他上下文中含义不同）。

### 插件

按项目安装的产品化能力包，组织动作、界面、Flow 依赖、扩展逻辑、权限声明和资源。插件是 Flow 的交互外壳与能力补充层，不是独立工作流引擎。

_避免：_ 脚本、扩展（分别只描述插件的一部分能力）。

### 插件动作

插件提供的一项可执行能力，可以出现在工具栏、菜单、右键菜单或插件面板中，也可以声明为 Webhook 入口。一个插件可以包含多个插件动作。

_避免：_ Flow、按钮（Flow 是实现方式，按钮只是入口形式）。

### 托管 Flow

随插件交付并由 VibeTable 安装、升级、校验和卸载的 Directus Flow。用户修改托管 Flow 后会形成偏离，不再被静默升级。

_避免：_ 内置 Flow、插件 Flow（无法准确表达所有权）。

### 外部 Flow

由用户在 Directus 中创建和维护、插件只保存绑定关系的 Flow。插件不得在升级或卸载时修改、替换或删除外部 Flow。

_避免：_ 自定义 Flow（托管 Flow 也可能包含自定义配置）。

### Flow 绑定

插件中的逻辑 Flow 标识与当前项目中 Directus Flow 实例之间的对应关系。绑定同时记录所有权、契约版本和校验状态。

_避免：_ Flow 配置（范围过宽）。

### 扩展逻辑

当 Flow 不适合完成某项客户端计算或本地交互时，由插件提供的补充逻辑。扩展逻辑补充 Flow，但不负责自由编排多个 Flow。

_避免：_ 本地 Flow、脚本引擎。

### 确认点

手动写入或危险 Flow 在第一次写入前等待 VibeTable 展示最终预览并取得用户决定的位置。确认点不是可转交、可恢复的业务审批。

_避免：_ 审批流（暗示持久化、可转交和可恢复）。

### 插件任务

一次插件动作的可观察执行，具有进度、结果、错误和协作式取消状态。关闭动作弹窗不会自动终止插件任务。

_避免：_ Flow 运行（本地和混合动作也会产生插件任务）。

### 偏离

当前 Directus 中的托管 Flow 定义与插件安装时记录的定义不同。偏离会暂停自动升级，并要求用户选择恢复托管版本或转为外部 Flow。

_避免：_ 损坏（偏离可能是用户有意修改）。

### 项目禁用

插件在当前项目中不提供任何动作或自动化的状态。任一必要 Flow 缺失、未绑定或契约不兼容时，插件整体进入项目禁用，而不是部分运行。

_避免：_ 卸载、暂停（插件和配置仍然存在）。
